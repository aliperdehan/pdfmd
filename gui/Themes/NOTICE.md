# Bundled themes

The thirteen `.cottheme` files here are CotEditor's built-in colour themes, copied unmodified from CotEditor 5
(<https://coteditor.com>, author 1024jp). Each file's `metadata.license` says "Same as CotEditor (Apache, ver.2)".
The licence text is in `LICENSE-Apache-2.0.txt`. Colophon reads the format; it is not affiliated with CotEditor.
